# Sesión web: dos horas sin actividad

1. Ejecutar únicamente `62_SESION_WEB_DOS_HORAS.sql` en el SQL Editor del proyecto existente de Supabase (requiere la actualización de sesiones SQL 33 ya instalada).
2. Desplegar el código de este ZIP en Vercel.
3. Recargar las pestañas de UnoMesa. Las sesiones ya vencidas deben iniciar sesión nuevamente.

Clics, escritura, desplazamiento y toques reinician las dos horas. Los chequeos automáticos no cuentan como actividad. El plazo nativo de Apple/Android sigue igual. No volver a ejecutar SQL base ni borrar datos.
