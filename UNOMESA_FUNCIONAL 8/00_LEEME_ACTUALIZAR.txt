PUBLICAR EN VERCEL
1. Descomprima UNOMESA_FUNCIONAL.zip. La carpeta UNOMESA_FUNCIONAL contiene
   package.json y el proyecto completo. Use el MISMO proyecto Vercel de UnoMesa.
2. Conserve las variables de entorno, dominio y conexión Supabase actuales.
   No cree otra base de datos. No copie valores de prueba de documentación.
3. Compruebe en Production:
   NEXT_PUBLIC_SITE_URL=https://www.unomesa.com
   Use ese valor si www.unomesa.com sigue siendo el dominio público principal.
   NEXT_PUBLIC_SEARCH_INDEXING no debe ser false en producción.
4. Publique la carpeta y espere a que el despliegue de Production esté listo.
5. Abra la web y pruebe Google, Cotizaciones → Pendientes y Seguridad.

GOOGLE SEARCH CONSOLE — DESPUÉS DE PUBLICAR
1. Abra https://search.google.com/search-console
2. Si ya existe unomesa.com, use esa propiedad. De lo contrario, Agregar
   propiedad → Dominio → unomesa.com (sin https ni www).
3. Complete la verificación DNS con el registro exacto que entregue Google,
   en el proveedor que administra el DNS del dominio. Conserve ese registro.
4. Abra https://www.unomesa.com/sitemap.xml y compruebe que incluya las URLs
   públicas. Luego, en Sitemaps, envíe esa dirección completa.
5. En Inspección de URLs, pruebe la URL publicada y solicite indexación de:
   https://www.unomesa.com/
   https://www.unomesa.com/es
6. Revise los estados en Search Console. La solicitud ayuda a descubrir las
   páginas, pero no garantiza la indexación ni una posición específica.
   El rastreo puede tardar días o semanas. No es necesario enviar diariamente.
Consulte SEO_PUBLICACION.txt para detalles y comprobaciones.
