UnoMesa — WhatsApp y navegación de listados
Actualización: 3 de noviembre de 2026

WhatsApp: cuenta y ventana
- El ícono discreto abre un diálogo con WhatsApp Web como primera opción y
  Aplicación WhatsApp como alternativa. No abre ninguna ventana al pulsar el ícono.
- Antes de abrir el chat se muestra el número guardado del restaurante y se pide
  confirmar manualmente que se usará esa cuenta. Cambiar canal o número vuelve a
  pedir confirmación. No se consulta ni se detecta la sesión de WhatsApp.
- «Otro número o sin acceso» muestra «Dispositivo no conectado al número
  configurado», aclarando que se basa en lo indicado por el usuario. Permite
  vincular la cuenta en WhatsApp Web o revisar Configuración si tiene permisos.
- Se reutiliza la referencia de la ventana abierta desde UnoMesa mientras el
  navegador lo permite. Se conserva el destinatario y el mensaje del nuevo chat.
  La ventana externa no obtiene acceso a la ventana de UnoMesa mediante opener.
- Si se cierra, se pierde la referencia por recarga o WhatsApp la aísla mediante
  sus políticas de seguridad, no se abre otra automáticamente: se muestra un aviso
  y «Abrir otra ventana». Solo una nueva acción expresa permite crearla.
- UnoMesa no puede descubrir ni controlar una pestaña de WhatsApp que se abrió
  manualmente o desde otra sesión. Para ese caso existe «Ya tengo WhatsApp Web
  abierto fuera de UnoMesa», con instrucciones y copia del teléfono/mensaje.
- No hay temporizadores de redirección ni detección ficticia de aplicaciones.
  El usuario revisa el mensaje y lo envía en WhatsApp. No cambia estados de reservas.

Teléfonos y configuración
- Para completar teléfonos locales se usa primero el país del restaurante y,
  si falta, el país detectado por la configuración existente de UnoMesa.
- Los números con +, 00 o enlaces oficiales conservan su destino internacional.
  Si faltan datos regionales o no se reconoce el país, se solicita corregirlos.
  La validación no asegura que el destinatario tenga una cuenta WhatsApp.
- El teléfono del cliente no se modifica al abrir un chat.
- Si falta el WhatsApp del restaurante, el administrador puede ir directamente a
  Configuración → General → WhatsApp, ingresar el número y guardar. Los usuarios
  sin permiso de configuración reciben una indicación para pedirlo al administrador.
- Guardar el número no vincula una sesión ni cambia la cuenta de WhatsApp activa.
  El enlace de configuración abre WhatsApp Web para realizar su vinculación allí.

PDF de cotizaciones
- Se conserva el botón PDF que ya existe al abrir la cotización, junto con Imprimir.
  La generación, diseño, paginación y descarga originales no cambian.
- Se retiró el botón adicional «Compartir PDF», su diálogo y el acceso adicional
  desde WhatsApp. Para obtener el archivo se utiliza Ver cotización → PDF.
- El botón WhatsApp abre el chat con texto. Para enviar la cotización por WhatsApp
  Web se adjunta manualmente el archivo obtenido con el botón PDF existente.
- No hay envío automático ni integración con WhatsApp Business Platform.

Primera y última página
Se agregaron «Primera» y «Última», además de «Anterior» y «Siguiente», en los
listados principales de cotizaciones, reservaciones y clientes. Se incluyen
recordatorios de cotizaciones, pendientes del equipo, historial de cambios,
papelera, usuarios, reportes e importación de clientes mediante el control común.

Los listados principales obtienen el total de resultados filtrados y leen solo
la página solicitada. No descargan el historial completo ni recorren todas las
páginas para llegar al final. Se conservan búsqueda, fechas, sucursal y orden.
El orden incluye el ID como desempate. Si se elimina la última página, se ajusta
al nuevo final. Cambiar filtros o sucursal vuelve a la primera página.
Los controles se desactivan durante la carga y en el extremo correspondiente;
se adaptan a pantallas pequeñas y tienen textos en español e inglés.
Los selectores auxiliares de vinculación/sucursales y el buzón que utilizan sus
propios cursores conservan su paginación anterior.

Instalación
Desplegar este proyecto actualizado en Vercel. No requiere SQL nuevo ni
credenciales de Meta. No se modificaron los proyectos nativos de las tiendas.
No se desplegó ni se alteraron datos de producción desde esta revisión.

Validación
Se verificó que la vista de cotización y el generador PDF conservan exactamente
su implementación anterior al botón adicional. Se retiraron los componentes y
pruebas que correspondían únicamente a compartir archivos.
Pruebas de teléfonos, mensajes, selección de cuenta, advertencia manual, ventana
reutilizable, bloqueo de emergentes y referencias inaccesibles. Regresiones de
paginación, contactos públicos, recordatorios y conversiones.
Compilación de producción y TypeScript: npm run build -- --webpack.
No se enviaron mensajes ni se modificó producción. La apertura real de WhatsApp
debe comprobarse tras desplegar en los dispositivos usados por el restaurante.
