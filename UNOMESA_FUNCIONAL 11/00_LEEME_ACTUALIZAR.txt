ACCESO MÁS SIMPLE Y GOOGLE EN IOS · BUILD 12
El acceso en modo app tiene Google como opción principal, correo → Siguiente
→ contraseña y Crear cuenta al pie. Conserva recuperación, registro en dos
pasos, validación de contraseña y una única prueba por cuenta nueva.
En Build 12, Google completa el intercambio dentro de la pantalla que inició
el acceso, sin cargar un documento intermedio. Después abre el dashboard
solo si la sesión, los permisos y la cuenta pasan sus validaciones.
Si seguridad cierra la sesión, se muestra un aviso en el ingreso.

Esta entrega requiere publicar esta web E instalar el nuevo proyecto iOS.
1. En Supabase → Authentication → URL Configuration → Redirect URLs, agregue
   com.unomesa.app://auth/google y guarde. Si ya existe, consérvelo.
   No cambie Site URL, las demás URLs ni el callback de Google Cloud.
2. Publique este ZIP en el proyecto Vercel existente (pasos abajo).
3. Abra el nuevo UNOMESA_iOS.zip → UnoMesa-iOS → UnoMesa.xcodeproj.
   Use su Team e identificador actuales, confirme Build 12 y ejecute en
   el iPhone con Command + R. No hace falta borrar la app anterior.
4. Pruebe Continuar con Google. iOS muestra su ventana segura para elegir
   cuenta; al terminar debe cerrarla y continuar en la aplicación.
   Cancelar permite reintentar; la sesión conserva las reglas existentes.
El host de Supabase de AppConfig.swift debe coincidir con el proyecto
Supabase usado en Vercel. Se conserva el host que ya tenía el proyecto.
El acceso y registro en modo app tienen diseño renovado, correo y contraseña
en pasos separados, Crear cuenta al pie y Google sobre el formulario. Conservan validaciones y prueba
única para cuentas nuevas. No hay un registro o base de datos separados.

49_SEGUIMIENTO_EVENTOS.sql y pulse Run. Tras Success, recargue UnoMesa.
Ejecute únicamente ese archivo; no los SQL históricos. Ya venía en el ZIP,
sin cambios. Crea su tabla y funciones de pendientes; no reescribe reservas,
clientes, cotizaciones, planes ni exenciones. Instalación y reinstalación
comprobadas con datos sintéticos. Si aparece un error, conserve el texto
completo para revisarlo; no intente resolverlo ejecutando los demás SQL.

PUBLICAR EN VERCEL
1. Descomprima UNOMESA_FUNCIONAL.zip. La carpeta UNOMESA_FUNCIONAL contiene
   package.json y el proyecto completo. Use el MISMO proyecto Vercel de UnoMesa.
2. Conserve las variables de entorno, dominio y conexión Supabase actuales.
   No cree otra base de datos. No copie valores de prueba de documentación.
3. Compruebe en Production:
   NEXT_PUBLIC_SITE_URL=https://www.unomesa.com
   Use ese valor si www.unomesa.com sigue siendo el dominio público principal.
   NEXT_PUBLIC_SEARCH_INDEXING no debe ser false en producción.
4. Publique la carpeta y espere a que el despliegue de Production esté listo.
5. Abra la web y pruebe Google, Cotizaciones → Pendientes y Seguridad.

GOOGLE SEARCH CONSOLE — DESPUÉS DE PUBLICAR
1. Abra https://search.google.com/search-console
2. Si ya existe unomesa.com, use esa propiedad. De lo contrario, Agregar
   propiedad → Dominio → unomesa.com (sin https ni www).
3. Complete la verificación DNS con el registro exacto que entregue Google,
   en el proveedor que administra el DNS del dominio. Conserve ese registro.
4. Abra https://www.unomesa.com/sitemap.xml y compruebe que incluya las URLs
   públicas. Luego, en Sitemaps, envíe esa dirección completa.
5. En Inspección de URLs, pruebe la URL publicada y solicite indexación de:
   https://www.unomesa.com/
   https://www.unomesa.com/es
6. Revise los estados en Search Console. La solicitud ayuda a descubrir las
   páginas, pero no garantiza la indexación ni una posición específica.
   El rastreo puede tardar días o semanas. No es necesario enviar diariamente.
Consulte SEO_PUBLICACION.txt para detalles y comprobaciones.

AJUSTE DE RECORDATORIOS
Modificar en Recordatorios abre la edición de la cotización vinculada.
Para agregar un pendiente, pulsa Pendientes en una cotización ya guardada.
Para cambiar su texto, entra a Pendientes y pulsa Modificar junto al texto.
Quitar sigue retirando únicamente el aviso, sin borrar la cotización.
